# BrewSwipe for Android

**[Download the latest BrewSwipe APK](https://github.com/Jospehty/brewswipe-android/releases/latest/download/BrewSwipe.apk)**

1. Open the link on your Android phone and download the file.
2. Open it. The first time, Android asks you to allow installs from your browser or Files app. Allow it, then tap **Install**.
3. Open BrewSwipe and sign up or log in.

The app updates itself when you open it, so you only need a new APK for bigger releases. Every build is listed under [Releases](https://github.com/Jospehty/brewswipe-android/releases).

This repo holds downloads only.
